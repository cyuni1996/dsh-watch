## 手表操作

| 操作 | 位置与结果 |
| --- | --- |
| 发消息 | 点输入框打字。鲸尾按钮发送，回复生成时变为停止方块。 |
| 语音输入 | 点麦克风开始，再点一次结束。电脑端 DSH 将录音转成文字，文字进入草稿后可编辑。 |
| 查历史或新建 | 左上角打开「航海日志」。可搜索历史，切换全部、置顶和归档。点加号新建，首次发出消息时在电脑创建会话。 |
| 管理会话 | 会话旁的三点进入详情，支持重命名、置顶、归档、恢复和「在电脑打开」。 |
| 操作消息 | 长按回复可以复制、朗读、引用或把最近的问题放回输入框。自己发出的消息可复制或放回输入框。 |
| 改模型 | 点聊天底部的模型栏。可跟随电脑，或选电脑提供的模型和该模型支持的思考强度。保存后下次发送生效。 |
| 查余量 | 轻点饭碗或从标题区下拉。显示内容取决于电脑 DSH 账号返回的余额和用量窗口。 |
| 操作确认 | 支持的提示会在手表显示。若提示「请在电脑处理」，在原桌面会话完成确认。 |
| 调整圆屏体验 | 表冠滚动，双击聊天区回到最新，子页左右滑或按返回。「设置 → 外观与阅读」可改字号、色调、历史密度、装饰与动效。 |

「设置」内可开关自动朗读和触感反馈。朗读由电脑生成音频，手表播放。电脑未配置适用转写或语音服务时，对应功能可能不可用。

## 管理连接

- **换电脑**。打开「设置 → 电脑连接」，选已保存的电脑，或添加另一台。草稿按电脑和会话保留。
- **手动局域网配对**。电脑端进入「设置 → 手表连接」，选择可访问的监听地址并生成十位码。手表使用「局域网扫描」或「手动连接」。首次添加或授权失效时输入十位码。已授权设备日常重连一般不需要再次输入。
- **外网连接**。先自行准备能够到达电脑插件 HTTPS 服务的入口，再在手表「外网连接」填写 HTTPS 地址和电脑生成的十位码。电脑 DSH 需运行，且手表要能访问该入口。日常使用优先局域网。
- **撤销设备**。在桌面端「手表连接」找到该设备并确认撤销。手表的访问权限会失效，再使用时需要重新授权。

无线调试六位码由手表系统生成，只用于安装。DSH 十位码由电脑插件生成，用于应用授权，五分钟有效且只能成功使用一次。

## 常见问题

**看不到「手表连接」**

确认已把插件装到正在使用的 DSH 配置，且开关已启用，再按提示重载。Desktop 与 Web 的插件配置是分开的。

**向导没有手表**

检查手表是否亮屏解锁、是否开启无线调试，以及电脑和手表是否同网。刷新设备。已配对但未连接时，从手表无线调试主页面取地址和端口。

**手表一直连接中**

核对电脑 DSH 正在运行、监听地址是手表可访问的网卡地址、端口未被防火墙或访客网络隔离。局域网扫描没有结果时可手动输入地址。

**更新提示签名不一致**

保留旧应用，检查 APK 来源。安装包必须与原应用签名一致才能覆盖。更多见 [首次连接教程](INSTALL.zh.md#更新)。

**声音、模型或余量没有数据**

查看桌面 DSH 的账号、模型和语音功能是否可用。余量可能因账号类型而不显示。若手表提示回电脑处理确认，在同一条桌面会话提交。

提交问题时请附插件与手表版本、手表型号和复现步骤。请遮盖配对码、设备标识、网络地址和私人会话。
