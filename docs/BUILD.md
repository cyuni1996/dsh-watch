# Build and package

Use Node.js 24.9+, a JDK 17+ installation, Android SDK 35, and Android build tools.

```sh
npm ci
npm test
cd packaging
./gradlew :app:testDebugUnitTest :app:lintRelease :app:assembleRelease
```

On Windows use `gradlew.bat`. The Gradle build writes the unsigned release APK to `packaging/build/app/outputs/apk/release/`. Sign it with the project’s existing release signing identity. Keep signing material outside the repository and use the same certificate for every update.

Verify that the APK is signed, uses the `org.dshwatch.app` package ID, and is not debuggable. Stage the signed APK:

```sh
./gradlew :app:stageInstallerApk -Pdshwatch.releaseApk=/absolute/path/to/signed.apk
cd ..
npm pack
```

The npm archive must contain `package/packaging/prebuilt/dsh-watch.apk`. Upload it to the tagged GitHub Release as **dsh-watch.tgz** for manual installs from the stable latest-release URL. Upload the APK as **dsh-watch.apk** and publish **SHA256SUMS** for both files.

Commit the verified APK at `packaging/prebuilt/dsh-watch.apk` alongside the matching plugin version. The DSH market installs this GitHub package and uses its version to offer updates. The Release tarball contains the same APK and can be used for manual installations.

The public blue-and-gold art is generated by `packaging/tools/generate_public_art.py` (Pillow). The Gradle wrapper license is under [docs/LICENSES](LICENSES/Gradle-LICENSE.txt).
